One of my earliest projects, this interactive birthday card was created during high school using Code.org's Game Lab. Users can interact with the card by clicking on various objects, which trigger visual animations and dynamic text changes.
 
Although simple in scope, this project introduced me to fundamental programming concepts such as conditional logic, event handling, and iterative design — and sparked my interest in creating interactive experiences through code.
